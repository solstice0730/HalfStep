# Design Handoff

디자인팀은 현재 GitHub에 직접 참여하지 않는다.

## 협업 방식

- 개발팀은 필요한 에셋, 일러스트, 아이콘, 화면별 상태를 GitHub 이슈에 명확히 남긴다.
- 디자인팀은 개발팀과 직접 컨택해서 필요한 산출물을 전달한다.
- 전달 파일은 가능하면 투명 배경 PNG 또는 SVG로 요청한다.
- 최종 전달된 에셋을 repo에 넣을 때는 개발팀이 파일명, 사용 위치, 화면 목적을 함께 기록한다.

## 이슈에 남겨야 할 내용

- 필요한 화면 또는 페이지
- 필요한 에셋 종류
- 권장 크기와 파일 형식
- 배경 투명 여부
- 사용 위치
- 마감일

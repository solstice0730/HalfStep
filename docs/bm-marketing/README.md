# BM/Marketing Documents

반걸음 BM/마케팅 문서는 매주 수정되며 GitHub 문서 PR로 누적한다.

## 운영 기준

- 매주 일요일 기준으로 최신 BM/마케팅 문서를 이 폴더에 추가한다.
- 파일명은 `YYYY-MM-DD_반걸음_BM_마케팅.docx` 형식으로 둔다.
- 회의에서 추가로 확인할 변경점이 있으면 같은 날짜의 `회의확인메모.md`를 함께 둔다.
- 이전 주 문서는 삭제하거나 덮어쓰지 않고 버전으로 보관한다.
- 주차별 DOCX는 조사·제안 원본이고, 회의확인메모는 제품과 발표에 적용할 결정 기준이다.
- 최종발표에 반영할 내용은 회의 결정 후 이슈와 발표 자료에 별도로 옮긴다.

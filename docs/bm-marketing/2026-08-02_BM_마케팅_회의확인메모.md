# 2026-08-02 BM/마케팅 회의 확인 메모

이 문서는 `2026-08-02_반걸음_BM_마케팅.docx`의 조사 내용을 검토한 뒤, 제품·개발·최종발표에 실제로 적용할 기준을 정리한다. 주차별 DOCX 원본은 보존하며 아래 결정이 충돌하는 문구보다 우선한다.

## 확정 기준

- 핵심 타겟은 생후 0~180일의 첫 부모다. 0~24개월은 검증 이후 확장 범위다.
- 구독은 `7일 전체 기능 체험 -> 월 8,900원 전면 유료` 구조다. 무료 티어는 두지 않는다.
- 가족방은 MVP에서 제외하고 커뮤니티를 포함한다.
- 현재 MVP는 기록, 캘린더, AI 일지 초안, AI 질문, 커뮤니티에 집중한다.
- 현재 AI 일지 구현은 기록, 보호자 메모, 사진 설명 텍스트를 사용한다. 실제 사진 픽셀을 모델이 분석하는 기능은 아직 구현·검증되지 않았다.

## 주차 문서 수정 기준

1. `사진 기반 AI 일지 경쟁자가 없다`는 표현을 사용하지 않는다. BabyLens 등 유사 기능이 확인되므로 차별점은 기능의 존재가 아니라 `0~180일 기록 맥락을 함께 활용하는 개인화 흐름`으로 검증한다.
2. 구독 화면에서 `Free/Premium`, `기록은 항상 무료`를 사용하지 않는다. `7일 체험/구독 후` 비교로 통일한다.
3. 가족방, 성장 리포트, 사진 자동 분석처럼 현재 범위 또는 구현에 없는 기능은 제공 중인 기능으로 표시하지 않는다.
4. 24개월 자동 갱신 상품은 현재 구독안에서 제외한다. Apple 표준 자동 갱신 기간에 24개월이 없으므로 별도 상품·법무·스토어 검토 전에는 월/6개월/12개월만 검토한다.
5. 장기권 환불액을 팀 자체 공식으로 확정하지 않는다. 실제 판매 시 앱스토어·구글플레이 정책과 국내 법률 검토 결과를 기준으로 고지한다.
6. `손익분기 전환율 0.8%`는 `트라이얼 변동비 회수 전환율 0.8%`로 구분한다. CAC, 인건비, 고정 인프라, 세금, 환불, 고객지원 비용을 포함한 사업 손익분기가 아니다.
7. AI 원가는 출시 모델과 실제 요청 로그가 정해진 뒤 다시 계산한다. 현재 코드의 기본 모델과 이미지 입력 여부가 문서의 GPT-4.1 mini 가정과 다르다.

## 개발·발표 반영

- 구독 목업은 월 8,900원이 검증 중인 가격임을 표시하되 무료 티어를 만들지 않는다.
- 발표에서는 AI가 현재 사진을 직접 분석한다고 말하지 않는다. `오늘 기록과 사진 설명을 바탕으로 초안을 작성한다`고 설명한다.
- 경쟁사 비교는 `없다`, `유일하다` 대신 경쟁 제품이 해결하지 못한 사용자 흐름과 검증할 차이를 제시한다.
- 산후조리원·보건소 인터뷰 결과는 기관명, 일시, 참여자 역할, 핵심 발언, 가격 반응, 후속 액션을 익명화해 #12에 남긴다.

## 남은 확인

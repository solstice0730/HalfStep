# 기록 / 사진 기반 AI 일지 PRD

## 목표

보호자가 아기의 수유, 수면, 소변, 대변 기록을 빠르게 저장하고 날짜별로 다시 확인한다. 오늘 촬영하거나 선택한 사진은 AI 일지 생성에 전달할 후보로 모은다.

## MVP 범위

- 수유, 수면, 소변, 대변 기록 생성
- 아기와 날짜, 기록 유형 기준 목록 조회
- 홈 빠른 기록과 기록 화면의 동일 API 사용
- 오늘 사진 후보의 선택, 제거, 빈 상태
- AI 입력 계약: 오늘 사진 URL/URI와 오늘 기록 ID 목록

## 제외 범위

- 기록 수정과 삭제
- 수유 및 수면 타이머
- 이유식 기록
- 사진 업로드 저장소
- AI 모델 호출, 프롬프트, 일지 저장

## 권한

- 모든 API는 로그인이 필요하다.
- 아기 소유자 또는 `baby_caregivers`에 등록된 보호자만 기록을 생성하고 조회할 수 있다.
- 작성자 ID는 요청으로 받지 않고 인증 사용자 ID를 사용한다.

## 기록 입력 규칙

| 기록 | 필수 입력 | 선택 입력 |
| --- | --- | --- |
| 수유 | 시간, 방식, 수유량 또는 수유 시간 | 좌우, 트림, 메모 |
| 수면 | 시작 시간, 종료 시간 | 낮잠/밤잠, 상태 |
| 소변 | 시간 | 양, 색상 |
| 대변 | 시간 | 양, 색상, 형태, 사진 URL |

## 완료 기준

- 네 가지 기록을 MySQL에 저장하고 같은 날짜 목록에서 다시 조회할 수 있다.
- 홈 빠른 기록과 Records 화면이 실제 API 응답을 사용한다.
- 로딩, 빈 상태, 오류와 재시도 상태가 제공된다.
- 오늘 사진이 없을 때 빈 상태가 표시되고, 사진이 있으면 AI 일지 후보로 확인할 수 있다.
